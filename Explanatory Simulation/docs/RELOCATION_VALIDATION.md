## التحقق

نجح البناء `npm run build` من الموقع الجديد. بقي تحذير Vite السابق عن حجم حزمة Scene.

نجحت جميع الاختبارات القائمة: **138** اختبار Node و**31** اختبار Python، دون إخفاق:

```powershell
node --test src/model/*.test.mjs
..\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

شُغّلت اختبارات Python والخادم خارج عزل أدوات الفحص؛ كان العزل يعلّق اتصال `asyncio` الداخلي عند `socketpair`. نجحت الاختبارات في البيئة المحلية العادية خلال نحو 3.4 ثانية. لم يحتج هذا إلى تغيير منطق الخادم أو تثبيت اعتماديات.

شُغّل `start.ps1 --no-browser` من المجلد الجديد. ثم نجح `start.ps1 --check` برمز خروج 0، عند استدعائه بمساره الكامل من مجلد `graduation project`؛ الناتج: `Local app healthy`. يعمل المختبر على `http://127.0.0.1:8765/`.

فُتحت الواجهة فعليًا من الخادم الجديد. عارض الشيفرة عرض `engine_env.py` والسطر 774 والمقتطف المحيط به، مما يؤكد وصوله إلى مصادر المشروع بعد النقل.
